# 3D Christmas Card 🎄

A beautiful, interactive 3D Christmas card built with Three.js. Share a personalized greeting with your friends and family!

[**Live Demo**](https://arbol-murex.vercel.app/)

## ✨ Features

*   **3D Tree**: A stylized, low-poly Christmas tree with ornaments and a glowing star.
*   **Interactive**:
    *   **Parallax**: Move your mouse to see the scene shift.
    *   **Music**: Background Christmas lo-fi music (with autoplay workaround).
    *   **Share**: Create a custom link with your friend's name.
*   **Responsive**: Works on desktop and mobile.
*   **Customizable**: Use URL parameters to personalize the greeting.

## 🚀 How to Use

Simply open the `index.html` file in your browser or deploy it to a static host like Vercel or GitHub Pages.

### Personalize via URL
Add `?n=Name` to the URL to change the greeting.
*   Example: `https://your-site.com/?n=Maria` -> **"¡Feliz Navidad, Maria!"**
